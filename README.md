## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git
- MongoDB

### 1. Clone the Repository

```bash
git clone https://github.com/selamde/Codveda-Internship.git
```

### 2. Navigate to the Project

```bash
cd Codveda-Internship/codveda_intern
```

### 3. Run the Backend

```bash
cd backend
npm install
npm run dev
```

### 4. Run the Frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

_Note: Configure the required environment variables before running the applications._
